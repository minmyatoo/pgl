helpHow to Use This Assistant

  1. Enter Call Number: Type the call number from the book spine (e.g., J 636.7 HAM)
  2. View Location: The system will show you the exact floor and shelf location
  3. Follow Map: Use the interactive map to navigate to the correct shelf
  4. Check History: Review your recent searches in the History tab
  5. Track Progress: Coordinators can view performance metrics in the Stats tab
Call Number Formats

Language-Specific Fiction (NEW!): [Language] [Author Code]

Examples:
• TAMIL MIYM = Tamil Fiction, author MIYM → Level 3 (3-35)
• MALAY MIYM = Malay Fiction, author MIYM → Level 3 (3-36)
• CHINESE MIYM = Chinese Fiction, author MIYM → Level 3 (3-26 to 3-32)
• ENGLISH MIYM = English Fiction, author MIYM → Level 3 (3-10 to 3-14)

Junior Fiction: [Section Code] [3-4 letters of author]

Example: JS STI = Junior Simple, author Stilton

Non-Fiction: [Section Code] [DDC Number] [Author]

Example: J 636.7 HAM = Junior, Dogs (636.7), author Hamilton

Adult Fiction (without language): [3-4 letter author code]

Examples: CAS, MIUS (defaults to English Fiction)

Shelf Number: [Level-Shelf] or just [Shelf]

Examples: 3-18, 4-26, or 18 (searches all levels)

DDC Only: [Number]

Example: 398.2 = Folktales
